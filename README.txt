GAFFER 27 - how to put it online
1. Upload ALL files in this folder (index.html, manifest.json, sw.js, icon-192.png, icon-512.png) to one folder on a host.
   Netlify Drop (app.netlify.com/drop): drag the folder in. GitHub Pages: push the files to a repo, enable Pages. Cloudflare Pages or itch.io (HTML5 game) also work.
2. Share the link. Players can play in the browser, or tap "Install app" / "Add to Home Screen" and play offline.
3. The "Download the game file" link on the main menu saves a copy of index.html they can open offline.
Saves are stored in each player's own browser.
